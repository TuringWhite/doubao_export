# Chrome 应用商店上架文案（可直接复制粘贴）

## 名称（≤ 45 字符）

```
豆包对话导出器 - 批量备份为 Markdown
```

## 简短描述（≤ 132 字符）

```
一键把豆包网页版的历史对话批量导出为 Markdown 文件，本地处理、不上传，支持智能体对话与分页拉取全部消息。
```

## 详细描述

```
豆包对话导出器，把你和豆包的历史对话一次性备份成 Markdown 文件。

【为什么需要它】
豆包没有官方的批量导出入口。想保存几十上百条对话，只能一条条复制粘贴——这是本扩展要解决的问题。

【它能做什么】
· 一键枚举侧边栏全部历史对话，逐条导出，单条失败不影响整体
· 每条对话独立生成一个 .md 文件，保留用户 / AI 角色与消息时间戳
· 兼容普通对话与智能体对话（两种页面的分页参数不同，已自动适配）
· 走页面同源的接口分页读取，不靠滚动屏幕，长对话也能拉全
· 复用浏览器已有登录状态，无需二次登录
· 实时进度显示，可在弹窗中查看进度与失败明细

【它不会做什么】
· 不收集账号密码
· 不采集浏览记录，不读取其他网站
· 不向开发者或任何第三方服务器发送数据
· 不含任何统计、埋点或广告

【使用方法】
1. 在浏览器打开并登录 https://www.doubao.com/chat
2. 点击工具栏中的扩展图标
3. 点击「开始导出全部对话」
4. 完成后，文件保存在下载目录的 doubao_export/ 子目录下

【隐私说明】
所有数据仅在你的浏览器与本机之间流转。导出时接口请求只发往 www.doubao.com，与豆包网页自身的请求一致。完整说明见隐私政策链接。

【说明】
本扩展为个人开发者的第三方工具，与豆包、字节跳动无关联，未获其授权或背书。请只导出你有权访问和保存的内容。
```

## 单一用途说明（Single purpose，审核表单必填）

```
将用户自己豆包账号下的网页版对话内容导出为本地 Markdown 文件。
```

## 权限理由（每个权限一句话，审核会看）

```
activeTab：用户点击导出按钮时，仅在当前豆包标签页注入导出脚本，不常驻其他页面。
scripting：注册读取接口请求参数的主世界脚本，并动态注入导出逻辑。
downloads：把生成的 Markdown 内容保存为本地文件。
主机权限 https://www.doubao.com/*：读取用户自己可见的对话内容，并调用页面同源接口分页获取历史消息。
```

## 数据使用声明（Data usage 表单）

- 是否收集或使用用户数据：**是**（网页内容 / 用户主动提供的内容），但仅在本机处理
- 是否将数据传输给第三方：**否**
- 是否用于广告、画像、信用评估、借贷：**否**
- 是否向第三方出售：**否**
- 是否使用远程代码（Remote code）：**否**（全部代码随包分发）
- 是否提供隐私政策链接：**是**（必填，见 PRIVACY.md 部署后的 URL）

> 填表要如实：扩展确实会读取用户对话内容，但不上传。不要为了"少填"而勾选"不收集任何数据"，一旦与实际不符反而容易被拒。

### 截图怎么截（建议 2 张）

1. **弹窗主界面**：打开豆包对话页 → 点扩展图标弹出面板 → `⌘⇧4` 空格选窗口截图，或用系统截图后裁到 1280×800。
2. **导出结果**：访达里 `doubao_export/` 文件夹 + 打开一个 .md 文件并排，同样裁到 1280×800。

截图中不要出现真实姓名、手机号、公司内部信息。对话内容建议用无关紧要的示例对话。
