隐私政策 · 豆包对话导出器

最后更新：2026-11-15 · 适用版本 1.1.2

本扩展只在你主动点击「开始导出」后，读取你当前登录的豆包账号中的对话内容，并在你的电脑上生成 Markdown 文件。 不收集账号密码，不采集浏览记录，不向开发者或任何第三方服务器发送任何数据。

本扩展会接触的数据

数据何时接触用途
你账号下的对话列表与对话内容（消息文本、角色、时间戳） 仅在你点击「开始导出全部对话」之后 生成 Markdown 文件，保存到你本机的下载目录
当前豆包页面的 URL 与页面自身已发起的接口请求参数 仅在导出过程中 复用页面同源请求参数，避免手工拼接会话标识

本扩展不会接触：账号密码、手机号、支付信息、浏览历史、其他网站页面内容、剪贴板、键盘输入。

数据如何流转

  • 导出所需的接口请求只发往 https://www.doubao.com，与豆包网页自身使用的接口一致，使用你浏览器中已有的登录状态。
  • 生成的文件通过浏览器下载能力直接写入你本机的下载目录（默认 下载/doubao_export/）。
  • 开发者服务器不参与上述任何环节。本扩展没有自建后端，不含统计、埋点或崩溃上报 SDK。

数据存储与保留

本扩展不存储你的任何数据。它不申请 storage 权限，不写 localStorage / IndexedDB，关闭弹窗即结束。导出的文件只存在于你本机，保留多久由你决定。

数据共享与出售

不共享、不转让、不出售。不存在「业务转让时迁移数据」的情形，因为本扩展从未持有你的数据。

权限说明

  • activeTab / scripting：在你点击导出时，向当前豆包标签页注入导出脚本，并注册读取接口参数的主世界脚本。
  • downloads：把生成的 Markdown 保存为文件。
  • 站点权限 https://www.doubao.com/*：读取你自己可见的对话内容，并调用页面同源接口分页获取历史消息。

你的控制权

  • 随时在 chrome://extensions/ 停用或卸载本扩展，即可完全停止其运行。
  • 已导出的文件由你自行管理，本扩展不会回读或上传。
  • 卸载后站点权限即被移除。

儿童

本扩展不面向 13 岁以下儿童，也不会有意收集其信息。

与第三方服务的关系

本扩展不是豆包、字节跳动或其关联公司的官方产品，未获得其授权、合作或背书。「豆包」等名称仅用于说明兼容的网站。请只导出你有权访问和保存的内容，并遵守你与豆包之间的服务条款。

变更

本政策如有更新，将修改本页顶部的「最后更新」日期，并在扩展的版本说明中注明。
