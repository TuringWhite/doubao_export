豆包对话导出器

把豆包网页版的历史对话批量导出为 Markdown —— 本地处理，不上传。

GitHub 仓库 下载最新版 隐私政策

它做什么

  • 一键枚举侧边栏全部历史对话，逐条导出，单条失败不影响整体
  • 每条对话一个 .md 文件，保留用户 / AI 角色与消息时间戳
  • 走页面同源接口分页，不靠滚动屏幕，长对话也能拉全
  • 全程在本机完成，文件直接写进下载目录

安装（开发者模式）

下载 Release 里的 zip 解压，或克隆仓库：

git clone https://github.com/TuringWhite/doubao_export.git

打开 chrome://extensions/ → 开启「开发者模式」→「加载已解压的扩展程序」→ 选择该目录。需要 Chrome 111+。

使用

登录 doubao.com/chat，点工具栏图标 →「开始导出全部对话」。完成后文件在 下载/doubao_export/。

本扩展为第三方工具，与豆包、字节跳动无关联，未获其授权或背书。
